# Homebrew tap

Homebrew casks by [sirruf](https://github.com/sirruf).

```sh
brew install sirruf/tap/irekobox
```

| Cask | What it is |
|---|---|
| [`irekobox`](Casks/irekobox.rb) | [Irekobox](https://irekobox.com): a native Mac app for Apple’s `container`, a Docker Desktop alternative |

The cask is updated with each Irekobox release. The app also updates itself.
